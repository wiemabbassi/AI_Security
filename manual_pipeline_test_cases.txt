TEST CASE 1: Normal Safe Query + Bi-Directional PII Masking & Restoration
================================================================================

Expected Result : PII masked on input (<PII_EMAIL_...>, <PII_EMPLOYEE_ID_...>), sent safely to LLM, then restored on output. Policy: ALLOW (HTTP 200).

Prompt:
"My name is John Doe, email is john.doe@acme-corp.com, phone is (555) 234-5678, employee ID is EMP-99887, and API key is sk-1234567890abcdef1234567890abcdef. Please summarize the IT support rules for employee onboarding."

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer test-key-123" \
